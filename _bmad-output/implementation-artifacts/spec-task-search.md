# North Star — searchable task inventory

Extend existing list_tasks/MCP/CLI/task-store pagination, NOT a second inventory. Search title and description with keywords (PostgreSQL websearch_to_tsquery), literal contains (ILIKE with escaped wildcards), and PostgreSQL regex (~*). Preserve default no-search behavior, cross-team ACL, existing open/claimed numeric totals, mine/status/project_prefix, stable rank ASC / updated_at DESC / key ASC continuation. Search never occurs after an arbitrary per-page limit. Include canonical search mode, normalized query, field selection and language in cursor binding; reject cross-filter cursor reuse.

## Frozen Search V1 contract
- Optional: search: string, search_mode: keywords|contains|regex (default keywords), search_fields: title|description|both (default both), search_language: simple|english|russian (default simple for identifiers, selectable Russian/English). Do not add separate competing search_tasks MCP tool.
- Empty/missing search must follow unchanged pagination and old MCP/CLI semantics; reject nonempty malformed/unknown mode/field/language rather than silently broaden.
- Keywords: websearch_to_tsquery with explicit fixed regconfig whitelist and weighted title>description. Query parsing is not raw SQL. Empty tsquery returns safe empty results or explicit invalid according to tests; no unbounded broadening.
- Contains: literal case-insensitive substring, escape user %/_/backslash; use SQL bind params, never interpolated regex or values.
- Regex: PostgreSQL case-insensitive ~*, max pattern bytes, fixed local statement_timeout, bounded page limit, validate SQLSTATE 2201B regex errors as safe input errors, no SQL injection. Some patterns cannot exploit pg_trgm; performance tests must include them and fail closed.
- Indexes: new additive 0020 task-search migration with pg_trgm GIN index on title+description or independent indexed expressions, plus GIN functional weighted to_tsvector; no modification of historical migrations. Benchmark EXPLAIN with 2k and preferably larger dataset.
- Signed cursor binds all search arguments/team and retains order rank/time/key, no duplicates for static fixture, explicit best-effort consistency for mutable inventory. Pagination page limit +1; totals stay team-wide status totals, not number of hits; document this clearly.
- Search V1 does not scan CrewSync notes, task result, attachments, metadata, events. No vector engine, no Elastic/Meili dependency. Relevance ranking optional later, NOT to disturb existing stable cursor.
